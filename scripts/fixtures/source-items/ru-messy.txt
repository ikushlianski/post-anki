# Как устроен кэш в Redis

Redis хранит данные в оперативной памяти, поэтому чтение занимает доли миллисекунды.

- TTL задаёт время жизни ключа, после которого Redis удаляет его сам
- Политика вытеснения allkeys-lru удаляет давно не использованные ключи, когда память заканчивается
- Персистентность через RDB делает снимок данных, а AOF записывает каждую команду

Пример установки времени жизни:

```
SET session:42 "token" EX 3600
```

Ключ session:42 исчезнет через час, потому что EX задаёт время жизни в секундах. Подробности есть в документации: https://redis.io/docs/latest/commands/expire/

Кэш нельзя считать надёжным хранилищем, так как при перезапуске без персистентности все данные теряются.

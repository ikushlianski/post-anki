- useEffectEvent is stable in React 19.2; call it only from inside effects, never pass to other components/hooks (https://blog.logrocket.com/react-useeffectevent/, https://reactuse.com/blog/react-useevent-hook.md).
- Window listener pattern: useEffect with empty deps adds the listener; handler is an Effect Event reading fresh state (https://medium.com/@nicholas.singgih/mastering-useeffectevent-in-react-best-practices-and-use-cases-a2501913c25f).
- Wrap the Effect Event in a local function inside the effect rather than passing it straight to addEventListener (https://zenn.dev/maguro_alterna/articles/17a0938c5b02a3) — unconfirmed by react.dev.
- Official react.dev page not in results; confirm against https://react.dev/reference/react/useEffectEvent before implementing.

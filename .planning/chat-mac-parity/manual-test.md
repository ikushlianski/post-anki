# Manual test: chat from triage, first prompts, Finish/Cancel, subject instructions

1. Mac dev copy, Triage: press C (or Chat) on an item, type a first prompt, send. Keep triaging. Open the Chat queue: the AI reply is already there.
2. Same with an empty prompt: the item lands in chat with no reply yet.
3. iPhone: Chat button opens the prompt sheet; swipe up still sends instantly.
4. In a chat, accept one proposed card: the bottom button reads Finish chat. Finish: item approved, thread gone.
5. New chat, accept nothing: button reads Cancel chat. Cancel (confirm on web): thread deleted, item back in triage. An Ask-AI chat item is marked rejected instead.
6. Cancel while the first reply is still generating: no stray reply appears later.
7. Web, subject menu on Business > Sales: chat instruction field shows the seeded text; edit and save. Open a chat on a Sales card: the reply follows the sales role.
8. A sub-subject without its own instruction (e.g. Cold sales after clearing it) uses the parent's.
9. Business > Sales has a B2B sales sub-subject.
10. Ask about a recent fact in an item chat: the reply names a web source in words.

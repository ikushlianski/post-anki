## Behavior
- `GET /knowledge-bits/export?format=json|csv` goes through the same global bearer auth as `/knowledge-bits/overview`. Bad format gives 400.
- Returns approved cards that have a live question variant (same set and preferred-variant rule as All cards): question, answer, example, subject name, source links, state, due date, interval days, ease, lapses, review count, last reviewed, and review history (time, grade, was-new, duration; JSON only has duration, CSV has "time grade" joined by " | ").
- Headers: `Content-Disposition: attachment; filename="post-anki-cards-YYYY-MM-DD.<ext>"`, `Cache-Control: no-store`.
- Streaming: keyset pages of 200 cards by id, written with backpressure; memory stays flat. A mid-stream failure destroys the connection so the download fails instead of looking complete.
- CSV: quotes, commas, CR/LF are quoted and quotes doubled; text cells starting with = + - @ tab or CR get a leading `'`.
- Web: All cards page shows "Download my cards: JSON CSV" links to `/api/knowledge-bits/export?format=...`.

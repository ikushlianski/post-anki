# Triage optional (off by default) + subject complexity levels

## Goal
- New cards skip triage and are studyable at once (global setting turns triage back on); the 493 waiting cards get approved by a dry-run-first script; the sweep cap counts unseen cards when triage is off; every subject has an inheriting Easy/Normal/Cram level that maps onto the existing retention multiplier, with a Good/Easy gap preview.

## Defaults chosen
- Triage off by default and applied by migration default `false`: matches the request; existing install flips on migrate.
- Auto-approve writes no feedback row: keeps triage stats (approval rate, per-model quality) about human decisions.
- Manual (typed) cards follow the same setting: same "new card" rule, one code path.
- Flagged (`review_flag`) cards are approved too, flag dropped like single approve: user asked for no triage; revisit if flagged cards prove noisy.
- Phrase sources keep first variant only: mirrors single approve, avoids studying every situation variant.
- Level presets Easy 0.87 / Cram 0.935 retention (multipliers 1.32 / 0.64): about 2x gap ratio inside the 0.5-2 clamp; no scheduler change.
- Explicit retention beats a level on the same subject; nearest ancestor setting either wins: simplest rule on the existing nearest-wins resolver.
- Preview uses a fixed reference card (5 d interval, ease 2.5), computed server-side: reuses `previewGradeIntervals`, honours exam caps, no client formula.
- Triage link stays visible while cards are still pending: avoids stranding leftovers before the script runs.
- Script skips subject-less cards unless `--include-unassigned`: request says "added to their subjects".
- Known gaps, not fixed: dedup and AI subject suggestion only see `pending` cards, so they stop with triage off; unseen-count also includes older approved-never-reviewed cards (dry run prints the total so the operator can see if the sweep would stall).
- Sub-subject creation from header menu, row actions and AI proposals stays name-only (inherit): no picker where the user only types a name.

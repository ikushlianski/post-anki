# Manual test — quality and Inngest batch

1. Mac app → Triage: press → (approves), ← (rejects), ↑ (sends to chat). Press N, type a note, press ⌘← — the card is rejected with that note. Shift+⌘← only selects text.
2. Web → Triage history: the "Card quality by model, all time" table lists models with approve/reject counts and an "unknown" row.
3. Web → a subject's extraction guidance form shows a default card-writing instruction.
4. Import a small .txt of notes: within ~10 minutes the notes leave "pending" and cards appear in triage.
5. Leave a triage session open over a day: its notes appear as style notes afterwards.

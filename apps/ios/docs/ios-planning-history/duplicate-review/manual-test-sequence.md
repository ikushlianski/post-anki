# Duplicate review: manual test sequence

1. Create two near-identical subjects on the server.
2. Settings > Tools > Duplicates > Subjects: Scan, confirm; see "Found N possible duplicates."
3. Tap "Keep <A>": confirm dialog names both subjects; merge; Courses tab shows one subject.
4. Try "Not duplicates" on another pair: it disappears.
5. Switch to Sources: Scan, confirm; Acknowledge one pair and Dismiss another.

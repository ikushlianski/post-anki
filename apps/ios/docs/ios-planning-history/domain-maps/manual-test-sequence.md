# Domain maps: manual test sequence

1. Settings > Tools > Knowledge maps: pick a subject, see the tree with percents and depth chips.
2. Open an area, change depth, go back: chip updated after reload.
3. Merge another area into it: confirm dialog shows, courses and sub-areas move.
4. Menu > Priority suggestions: run review (confirm), accept and reject one.
5. Menu > Document scan suggestions: scan (confirm), triage a new area and a replacement.
6. Menu > What to learn next: get recommendations (confirm), accept one (confirm), tap "Open course".
7. Area > a course: Suggest areas (confirm), confirm one with a depth, reject another.
8. Settings > Tools > Refocus suggestions: open a course, dismiss a suggestion.

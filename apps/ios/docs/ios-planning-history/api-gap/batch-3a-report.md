- Home: a "Start your day" card under Due today opens today's question (answer, pass/fail feedback, open topic) and the due queue.

- Notion import: paste an id or link, import in chunks with Continue, detection runs at the end.
- Review tab: per-source "Regenerate items" (confirm, poll every 3 s for up to 5 minutes); item detail: "Generate more question variants".
